# AI 财富创造观察站（ai-wealth-monitor）

跟踪 **AI 重塑生产方式、创造新增物理财富** 的可实时更新开源仪表盘。

## 唯一标准

本项目的唯一评判标准是：

> **AI 是否创造了更多新增（物理）财富？**

所有信号先过三问筛选器，只有"新增"进入主榜：

| 类型 | 定义 | 例子 | 处理 |
|---|---|---|---|
| **转移** | 零和：把已有财富从一处搬到另一处，不新增 | 卖课、信息差、低端外包转手、AI 仿品抢同质市场 | 不进主榜，可进"噪音样本"栏反衬 |
| **释放** | 提效：同样投入产出更多，但前提是资源流向新产出 | 自动化重复劳动、成本下降、人均产出提升 | 进"释放"栏，标注前提条件 |
| **新增** | 终局：做出原本做不出的东西 | 新产品/新产线/新材料/新商业模式，物理产能扩张 | **进主榜**，最终验证标准 |

**最终验证锚点 = 物理产出增量**：生产企业披露的成本降幅、产能提升、资本开支。模型/agent 只是前瞻信号，不算数。

## 观察链

```
认知层(模型/agent) → 执行层(工具) → 物理载体层(机器人/产线) → 生产企业(最终闭环) → 经济验证(成本↓/产能↑)
```

## 观测指标（贯穿全站的标尺）

- **agent 自主完成率** —— 决定替代速度
- **单位任务成本** —— 决定普及速度
- **物理产出增量**（企业披露成本降幅/产能提升）—— **最终验证**

## 目录结构

```
ai-wealth-monitor/
├── README.md            # 本文件
├── PLAN.md              # 总规划 + 同类项目调研
├── docs/
│   ├── AI副业认知地图.md       # 100 篇中文生态帖子的提炼
│   ├── 生产方式重塑信号清单.md  # 左右列信号基础语料
│   ├── cocoloop-追文目录.md    # 抓取追文索引
│   └── sources.md        # ★ 总信息来源清单
├── data/
│   ├── raw/cocoloop/     # 100 篇原始抓取资料
│   ├── signals.json      # 财富信号（新增物理财富实证）
│   ├── watchlist.json    # 盯人名单 + 状态
│   ├── waves.json        # 左右列重塑信号
│   └── timeline.json     # 事件时间线
├── collectors/           # 各源采集器
├── skills/               # 信源维护 skill（借鉴 ai-news-radar 伯乐）
├── .github/workflows/    # Actions 定时抓取
└── public/index.html     # 静态页（GitHub Pages）
```

## 数据流

```
sources.md(渠道清单) → collectors/抓取 → data/*.json → AI提炼+人审 → public/index.html
    状态：LIVE(自动) / STALE(过期) / MANUAL(人工录入)
```

## 页面板块

1. 唯一标准横幅 + 三问筛选器
2. 财富信号榜（新增物理财富实证）
3. 盯人名单（认知层 / 物理引擎 / 生产企业闭环）
4. 左右列重塑信号（左列消失 / 右列冒头）
5. 事件时间线 + 数据源状态条
