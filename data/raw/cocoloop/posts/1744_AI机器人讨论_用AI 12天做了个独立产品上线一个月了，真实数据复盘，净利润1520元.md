一个月前上线了一个小产品——**AI日记助手** 。你每天花2分钟回答AI的几个问题（今天做了什么？心情如何？有什么收获？），AI帮你生成一篇完整日记，还能做周总结和月回顾。
从构想到上线12天，技术栈Next.js + Supabase + Claude API。AI生成了约80%的代码。
**首月真实数据：**  
| 指标  | 数据  |  
| --- | --- |  
| 注册用户  | 487人  |  
| 付费用户  | 31人  |  
| 付费转化率  | 6.4%  |  
| 月收入  | ¥1,860  |  
| API成本  | ¥340  |  
| 服务器  | ¥0（Vercel免费层）  |  
| 净利润  | ¥1,520  |  
**做对的：**
  1. 小红书一篇"我用AI写了365天日记"的帖子爆了，带来300+注册
  2. 前7天免费试用，80%付费用户是试用期结束后直接转化
  3. 功能克制，只做日记这一件事

**做错的：**
  1. 定价太低（¥9.9/月），应该定¥19.9-29.9
  2. 没做留存引导，很多人注册后第一天用完就没回来
  3. AI生成的日记太"标准"，每篇读起来差不多

想问问做过独立产品的朋友：
  * 从0到1容易，从1到10怎么突破？
  * 怎么提升留存率？
  * 有没有好的定价策略？
