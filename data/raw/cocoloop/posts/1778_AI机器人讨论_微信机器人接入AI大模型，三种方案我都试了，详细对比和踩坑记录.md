很多人想做微信AI助手——在微信里直接跟AI对话。我试了三种方案，各有优劣。
**方案1：企业微信应用**
  * ![:white_check_mark:](https://www.cocoloop.cn/images/emoji/twitter/white_check_mark.png?v=15) 官方支持、稳定、不会被封
  * ![:cross_mark:](https://www.cocoloop.cn/images/emoji/twitter/cross_mark.png?v=15) 需要企微账号，用户不在个人微信里用
  * 适合：企业内部
  * 开发：Claude Code帮我1天搞定

**方案2：个人微信协议（有风险）**
  * ![:white_check_mark:](https://www.cocoloop.cn/images/emoji/twitter/white_check_mark.png?v=15) 体验最好，个人微信直接用
  * ![:cross_mark:](https://www.cocoloop.cn/images/emoji/twitter/cross_mark.png?v=15) **有封号风险** ，协议随时可能失效
  * 适合：个人实验，**不建议商业使用**
  * 工具：wechaty

**方案3：公众号/服务号**
  * ![:white_check_mark:](https://www.cocoloop.cn/images/emoji/twitter/white_check_mark.png?v=15) 完全合规，可积累粉丝，商业化潜力
  * ![:cross_mark:](https://www.cocoloop.cn/images/emoji/twitter/cross_mark.png?v=15) 5秒超时限制需要异步处理，不支持实时对话感
  * 适合：面向公众的AI服务

公众号方案的开发者来说说**5秒超时** 怎么解决。
微信公众号的被动回复API要求5秒内返回响应。但AI生成回答通常要10-30秒。直接超时就回复失败了。
**解决方案** ：
  1. 收到消息后立即返回"正在思考…"（5秒内）
  2. 后台异步调用AI API
  3. AI回答生成后，用**客服消息接口** 主动推送给用户

代码核心逻辑：

```

用户发消息 → 服务端收到 → 立即回复"⏳ AI正在思考..." → 异步调AI → AI回复好了 → 用客服消息接口推送

```

注意：客服消息接口需要**已认证的服务号** 。未认证的订阅号用不了。
如果只是订阅号，可以换个思路：回复一个链接，用户点进去看AI的回答（做一个简单的web页面）。体验差一点但能用。
