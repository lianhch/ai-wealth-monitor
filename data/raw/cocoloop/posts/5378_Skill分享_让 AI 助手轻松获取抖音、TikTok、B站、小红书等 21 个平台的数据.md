  1. 访问 MaxHub 官网
  2. 注册账号并登录
  3. 在控制台创建 API Key

###  [](https://www.cocoloop.cn/t/topic/5378#p-53367-h-17)第二步：配置环境变量

```

export MAXHUB_API_KEY=mh_sk_your_api_key_here

export MAXHUB_BASE_URL=https://www.aconfig.cn

```

###  [](https://www.cocoloop.cn/t/topic/5378#p-53367-openclaw-skill-18)第三步：在 OpenClaw 中安装 Skill
  1. 打开 OpenClaw 平台
  2. 进入 Skill 市场
  3. 搜索 `maxhub-douyin` 或其他需要的 Skill
  4. 点击安装

###  [](https://www.cocoloop.cn/t/topic/5378#p-53367-h-19)第四步：开始使用
直接用自然语言与 AI 对话即可：

```

用户: 帮我看看抖音今天的热搜
```
