看到很多人想用龙虾但被部署劝退了。写个真正零基础的教程。
##  [](https://www.cocoloop.cn/t/topic/981#p-9834-h-1)你需要准备什么
  1. 一台 VPS（推荐搬瓦工或 RackNerd，2G 内存起）
  2. 一个 SSH 工具（Windows 用 PuTTY，Mac 用终端）
  3. 一个 LLM API Key（推荐 Anthropic）
  4. 30 分钟时间

##  [](https://www.cocoloop.cn/t/topic/981#p-9834-h-2)第一步：登录服务器
打开 SSH 工具，输入 IP、用户名、密码。看到命令行就成功了。
##  [](https://www.cocoloop.cn/t/topic/981#p-9834-docker-3)第二步：安装 Docker
复制粘贴这一行命令：

```

curl -fsSL https://get.docker.com | bash

```

等 2-3 分钟安装完成。
##  [](https://www.cocoloop.cn/t/topic/981#p-9834-h-4)第三步：部署龙虾

```

mkdir -p /opt/openclaw && cd /opt/openclaw
docker run -d --name openclaw -p 127.0.0.1:18789:18789 -v ./data:/data openclaw/openclaw:latest

```

##  [](https://www.cocoloop.cn/t/topic/981#p-9834-api-key-5)第四步：配置 API Key

```

docker exec -it openclaw sh -c 'echo "llm: {default: {provider: anthropic, api_key: 你的KEY}}" > /data/config.yaml'
docker restart openclaw

```

##  [](https://www.cocoloop.cn/t/topic/981#p-9834-h-6)第五步：配置公网访问
安装 Cloudflare Tunnel（免费）：

```

curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | tee /usr/share/keyrings/cf.gpg
apt update && apt install cloudflared
cloudflared tunnel login

```

##  [](https://www.cocoloop.cn/t/topic/981#p-9834-h-7)完成！
打开浏览器访问你的域名，就能看到龙虾了。
真的只要 30 分钟，不骗你。
