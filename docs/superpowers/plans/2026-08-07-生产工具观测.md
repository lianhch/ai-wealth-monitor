# AI × 生产工具观测（生产工具雷达）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `data/tools.json` + 数据驱动的"生产工具观测"页面板块，展示 AI×具体生产工具的"人力↓/产量↑"双指标，并把政府采购/央企采购清单作为苗头指标层。

**Architecture:** 纯静态 JSON + 前端渲染，复用现有 GitHub Pages 架构。`tools.json` 放入 `data/`，由 `scripts/build.py` 复制到 `public/data/`，`index.html` 用 fetch 读取并按 `price_tier` 分组渲染。采购清单工具标 `channel: procurement`，用特殊标记区分（苗头指标，不进主榜）。

**Tech Stack:** JSON（无 schema 校验框架，用 python json.load 验证）、原生 JS（无框架）、GitHub Actions（已有 build 流程）。

**Spec:** `docs/superpowers/specs/2026-08-07-生产工具观测-design.md`

## Global Constraints

- 所有新 JSON 必须通过 `python -c "import json; json.load(open(path, encoding='utf-8'))"` 验证。
- `metrics.operators_before/after` 与 `output_before/after` 允许 `null`（未知），禁止编造数字；有参数就填，没有填 `null`。

删除原有的 `const TOOLS = [ ... ];` 静态数组和对应的 `renderTools()` 函数（旧实现写死 3 行 HTML），替换为数据驱动版本：

```js
function renderTools(d) {
  const list = (d && d.tools) || [];
  const tiers = ['personal', 'small_biz', 'enterprise'];
  if (!list.length) { el('tools').innerHTML = '<div class="empty">暂无工具数据</div>'; return; }
  el('tools').innerHTML = tiers.map(tier => {
    const items = list.filter(t => t.price_tier === tier);
    if (!items.length) return '';
    const head = `<div class="trends-meta" style="margin:4px 0 2px;font-weight:600">${SCALE_ZH[tier]} · ${tier}</div>`;
    return head + items.map(t => `
      <div class="trend">
        <span class="rname"><b>${t.name}</b>
          <div class="rdesc">${t.ai_evidence || ''} · 价格分层：${SCALE_ZH[t.price_tier]}</div>
          <div class="rdesc">
            <span class="badge ${t.channel === 'procurement' ? 'b-new_pending' : ''}">${CHANNEL_ZH[t.channel] || t.channel}</span>
            <span class="badge">${TOOL_STATUS_ZH[t.status] || t.status}</span>
            人力：${t.metrics.operators_before === null ? '?' : t.metrics.operators_before}→${t.metrics.operators_after === null ? '?' : t.metrics.operators_after}人
            · 产量：${t.metrics.output_before === null ? '?' : t.metrics.output_before}→${t.metrics.output_after === null ? '?' : t.metrics.output_after}
          </div></span>
        ${t.source_url ? `<span class="rage"><a href="${t.source_url}" target="_blank" rel="noopener">来源</a></span>` : ''}
      </div>`).join('');
  }).join('');
}
```
